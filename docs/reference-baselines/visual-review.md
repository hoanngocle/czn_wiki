The source's five dark navigation icon requests return 404. The product intentionally uses available local light icons instead of broken images. One source `vanguard` job icon has invalid contents; the product uses a diamond fallback. Source action buttons for Counseling, Town Visit and Share are shown as unavailable because their destinations/data are outside the captured milestone. Cards/other game groups are likewise visibly disabled rather than pretending to be implemented. The product does not display Prydwen content.

The remaining visible differences are small icon/button styles, text rendering, and spacing, especially within card descriptions and mobile Manifest Ego. No screenshot claims the missing 37 combatant details are available; only Renoa has imported detail. `product-capture.json` records zero console errors, page errors, failed requests and broken images across all 18 product screenshots. The source's intentionally blocked external tracker and missing icons are documented in `baseline-notes.md`.
